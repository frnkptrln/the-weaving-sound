# temporal-binding

## System

A single pitch set moves continuously between simultaneous and sequential
presentation. Nothing about the notes changes; only their temporal binding does.

## Sound mapping

- density shortens the interval between note onsets.
- motion moves from a stable chord toward an arpeggiated stream.
- space lengthens release and opens the stereo field.
- brightness, grit, and tension shape the shared subtractive voice.

## Listening question

At what point does one harmonic object become a sequence of separate events?
Does that boundary remain in the same place when motion, density, or space changes?

## Run

Run ./start.sh and stop with Ctrl+C or evaluate ~temporalBindingStop.().
